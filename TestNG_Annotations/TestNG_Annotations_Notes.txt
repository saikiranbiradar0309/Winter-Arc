01. What are Annotations in TestNG?
	- In TestNG, annotations are special keywords that start with @ and tell TestNG what a 
	  particular method/class is supposed to do and when it should execute.
	 
	
	- For Example:
		@Test
		public void loginTest()
		{
			System.out.println("Login test");
		}
	
	- Here:
		@Test
			- is a TestNG annotation
	
	
	- It tells TestNG:
		"This method is a test method. Execute it as a part of the test"

		
		
===================================================================================


02. Why do we need Annotations?
	
	- Without annotations, TestNG wouldn't know
		a. Which method is a test
		b. Which method should execute before the test
		c. Which method should execute after the test
		d. Which method should execute before all tests
		e. Which method should execute after all tests
		f. Whether a test depends on another test
		g. Whether a test should be skipped
		h. What priority a test should have
	
	
	- Annotations basically give instructions to the TestNG framework.
		

===================================================================================


03. Most important TestNG annotations
	
	a. @Test
			- Defines a test method
	
	
	b. @BeforeMethod
			- Runs before every @Test method
	
	
	c. @AfterMethod
			- Runs after every @Test method
	
	
	d. @BeforeClass
			- Runs once before the first test method in the class
	
	
	e. @AfterClass
			- Runs once after all test methods in a class
	
	
	f. @BeforeTest
			- Runs before the <test> section in TestNG XML
	
	
	g. @AfterTest
			- Runs after the <test> section
	
	
	h. @BeforeSuite
			- Runs once before the entire suite
	
	
	i. @AfterSuite
			- Runs once after the entire suite
