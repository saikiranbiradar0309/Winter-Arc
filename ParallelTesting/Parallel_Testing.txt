01. What is Parallel Testing?
	
	- Parallel Testing means executing multiple test cases simultaneously instead of 
	  executing them one after another.
	  
	- Imagine you have 5 Selenium Test cases:
	  a. Test Case 1: Login
	  b. Test Case 2: Add to Cart
	  c. Test Case 3: Search Product
	  d. Test Case 4: Checkout
	  e. Test Case 5: Logout
	
	
	- Sequential Execution
	  
	  Each test waits for the previous test to finish.
	  
	  Login				--> Test 1
	  Add to Cart		--> Test 2
	  Search Product	--> Test 3
	  Checkout			--> Test 4
	  Logout			--> Test 5
	  
	  Total time is approximately the sum of all five test durations.
	  
	
	
	- Parallel Execution
	  
	  Multiple tests run at the same time in separate browser sessions
	  
	  Login 				--> 1
	  Add to Cart			--> 2
	  Search Product 		--> 3
	  Checkout				--> 4
	  Logout				--> 5
	  
	  
	  For Example, if each test takes 20 seconds
	  a. Sequential: approximately 100 Seconds
	  b. Parallel with 5 available threads: approximately 20 seconds, excluding
	  			browser startup and other overhead
	

====================================================================
	
	
02. What is ThreadLocal<WebDriver>?
	
	- When multiple selenium tests run in parallel, each test needs its own 
	  independent WebDriver instance.
	
	- If multiple threads share a single WebDriver object, they can interfere with
	  one another. One test might navigate to another test's page, close its browser,
	  or cause session-related exceptions.
	
	- ThreadLocal<WebDriver> solved this by storing a separate WebDriver for each 
	  executing thread.
	
	- Think of ThreadLocal like assigning a separate locker to each employee.
	  Each employee can access only their own locker, rather than sharing one locker
	  with everyone.

03. How to remember ThreadLocal
	
	Method							Meaning											Memory trick
	ThreadLocal<WebDriver>		Creates a thread-specifci storage variable				Create
	set(driver)					Stores the WebDriver for the current thread				Save
	get()						Retrieves the WebDriver for the current thread			Retrieve
	remove()					Clears the current thread's stored value				Clean

Step 1: Create private static ThreadLocal<WebDriver> object in global level
		
		private static ThreadLocal<WebDriver> threadLocal 
					= 	new ThreadLocal<WebDriver>();



Step 2: Set WebDriver instance in ThreadLocal object using set() method
		
		WebDriver driver = new ChromeDriver();
		
		threadLocal.set(driver);


Step 3: Get WebDriver instance from ThreadLocal object using get() method
			We use these WebDriver instance to launch isolated WebDriver instance,
			we these in test cases
			
		
		WebDriver driver = threadLocal.get();

Demo 1: Getting title for Google and Facebook using Parallel Testing


package parallelTesting;

import org.testng.annotations.Test;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.testng.annotations.Test;

public class Demo1 {
	
	private static ThreadLocal<WebDriver> threadLocal =
				new ThreadLocal<WebDriver>();
	
	
	public static WebDriver getInstance()
	{
		WebDriver driver = new ChromeDriver();
		threadLocal.set(driver);
		
		return threadLocal.get();
	}
	
	
	@Test
	public void testCases1() throws InterruptedException
	{
		WebDriver driver = Demo1.getInstance();
		driver.get("https://www.google.com");
		String title = driver.getTitle();
		System.out.println(title);
		
		Thread.sleep(4000);
		
		driver.quit();
	}
	
	
	@Test
	public void testCases2() throws InterruptedException 
	{
		WebDriver driver = Demo1.getInstance();
		driver.get("https://www.facebook.com");
		String title = driver.getTitle();
		System.out.println(title);
		
		Thread.sleep(4000);
		
		driver.quit();
	}
}

package parallelTesting;

import org.testng.annotations.Test;
import java.time.Duration;

import org.openqa.selenium.By;

import org.openqa.selenium.support.ui.WebDriverWait;
import org.testng.annotations.Test;

public class SauceDemo {

	private static ThreadLocal<WebDriver> threadLocal =
			new ThreadLocal<WebDriver>();
	
	
	public static WebDriver getInstance()
	{
		WebDriver driver = new ChromeDriver();
		threadLocal.set(driver);
		return threadLocal.get();
		
	}
	
	@Test
	public void testCase1() throws InterruptedException
	{
		WebDriver driver = SauceDemo.getInstance();
		
		WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(30));
		
		driver.get("https://www.saucedemo.com/");
		
		
		Thread.sleep(2000);
		
		wait.until(ExpectedConditions.
				visibilityOfElementLocated(By.id("user-name")))
					.sendKeys("standard_user");
		
		
		wait.until(ExpectedConditions.
				visibilityOfElementLocated(By.id("password")))
					.sendKeys("secret_sauce");
		
		Thread.sleep(2000);
		
		wait.until(ExpectedConditions.elementToBeClickable(By.id("login-button"))).click();
		
		Thread.sleep(2000);
		
		wait.until(ExpectedConditions.
				elementToBeClickable(By.id("add-to-cart-sauce-labs-bike-light"))).click();
		
		Thread.sleep(2000);
		
		wait.until(ExpectedConditions.
				elementToBeClickable(By.className("shopping_cart_link"))).click();
		
		Thread.sleep(2000);
		
		wait.until(ExpectedConditions.elementToBeClickable(By.id("checkout"))).click();
		
		Thread.sleep(2000);
